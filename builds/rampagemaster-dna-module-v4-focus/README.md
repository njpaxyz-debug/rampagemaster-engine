# RampageMASTER DNA Module v4 Focus

This checkpoint corrects the previous overexpanded DNA preview by reducing the working set to readable, renderer-ready canon archetypes.

Principle: fewer categories, stronger structure.

Coverage:
- 24 genes instead of a runaway 74-gene preview surface
- 12 flagship kaiju archetypes
- 5 growth stages
- 6 player pressure routes
- each archetype has a complete renderer blueprint: body, head, eyes, limbs, tail, armor, horns, wings/fins, special organs, surface language, motion loop, city interaction, evolution branch, and readable silhouette notes
- preview shows one selected kaiju with an evolution chain and a compact roster, not endless cards

Integration rule: this focus module becomes the design-facing DNA spec; the larger v3 matrix can remain as a hidden entropy layer if needed, but the visible game should use these curated archetypes first.
