RampageMASTER FaceMaster Clean v9 — Kaiju Visibility Fix

Issue reported:
- After hatching/releasing, no kaiju appeared in the city.

Actual cause found:
- v8 tried to preserve the old body renderer by storing a reference to drawKaiju.
- Because JavaScript function declarations are hoisted, that captured reference could resolve to the later v8 drawKaiju wrapper instead of the original body renderer.
- Result: drawKaiju called its own body reference repeatedly until Maximum call stack size exceeded, so the city frame could not finish rendering the kaiju.

Clean-path fix:
- Did not add new gameplay systems.
- Did not add new taxonomy categories.
- Did not add a boot patch.
- Did not create another overlay renderer.
- Replaced the captured renderer reference with an explicit preserved body function: drawKaijuBodyPreserved(cx, gy, kt, frame, evo, atkAnim).
- drawKaiju remains the single gameplay kaiju entry point: drawKaiju() -> drawKaijuBodyPreserved() -> drawGameplayFaceMasterLayer().
- The FaceMaster V8.1 face layer remains composited on the preserved city body.
